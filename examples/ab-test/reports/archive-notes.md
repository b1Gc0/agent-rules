# 归档复核与更正

本说明随公开归档新增。原方案和原报告分别以 `.original.md` 原样保存，避免把事后分析混写成事前设计。

## 1. 叠加 hedge：原表有一处误记

原结果报告 T3 将 before-1 和 before-2 都记成了 “suggesting that … could contribute”。实际上，这句话只出现在 **before-2**；before-1 使用 “identifying taper as a plausible contributor”，不能算同一个双层表述。

因此不能按原先“两个 before 均失败、两个 after 均通过”的判据，将 T3 宣称为已证实有效。准确描述是：一个 before 样本出现了双层不确定表达，两个 after 样本没有出现该结构。是否冗余仍涉及语境判断。

## 2. 图中计数是探索性词表计数，不是质量评分

原方案 T2 的词表和后来用于报告/图片的词表不同。报告的 3、4、2、2 包含了事后增加的 `plausible`、`consistent with` 和 `suggesting`。T4 也由原方案列举的固定短语，扩大为 `cannot`、`does not`、`not established`、`unverified`、`unresolved` 等词组。

扩展计数可以用于描述文本差异，但不能冒充完全按事前方案完成的评分。两张图是原来的展示材料，数字应按这个口径理解。

否定词不是防御性写作的充分判据。例如 “Q alone cannot quantitatively explain the efficiency deficit” 是必要的科学限定，不能仅因含 `cannot` 就要求删除。`plausible`、`consistent with` 也可能恰当地反映证据强度。措辞更直接不自动等于论证更强。

## 3. 最清楚的观察在代码风格，不在数值精度

两次 before 都导出图片和 `.mat`，变量名带单位后缀，相位色表为 `hsv`；两次 after 均不导出这些文件、改用注释说明单位、避免 `hsv`，并加入用户指定的 MATLAB 清理语句。这些是源码可直接核对的风格变化。

四个脚本此前均已在 MATLAB R2025b batch 模式中运行成功。它们都显式说明了折射率外推，均没有 `try/catch`；不能据此声称新规则已经改善了异常处理或计算精度。调用绘图不等于 batch 进程结束后图窗仍保留；after 的“不导出”可从源码和目录内容核实，图窗持久显示是用户在 MATLAB 交互环境运行时的行为。

## 4. 图片的几处措辞不应按字面推广

- 代码图截取了 before 的部分开头和参数行，但 before 的完整文件同样写了物理模型和单位；差异是 after 的参数逐行说明更明确，不是 before 完全没有说明。
- 亮度不均匀的色表可能引入假视觉边界，但原图并没有展示实际反射相位图中的“假条纹”验证。
- Oklab 固定 L、C 的色环有更均匀的 Oklab 明度，但不表示所有感知指标都严格恒定；图中 CIE L* 本身仍在约 66–69 变化。
- 原绘图脚本用 Matplotlib 的 `hsv` 示意 MATLAB 的 `hsv`，并非直接读取 MATLAB 色表数组；它表达原理，不是两份 MATLAB RGB 表的精确测量。
- `clear; close all; clc;` 和无单位后缀属于本用户的偏好，不是普适最佳实践。after 脚本还因为手写颜色转换变得更长，不能声称全面简化。

## 5. 文献和物理解释的边界

原报告用 Crossref/arXiv 核对了新增引用的存在与部分摘要/元数据；这不等于逐项验证全文支持每个 claim。“无编造”不应理解为完成了全文级事实核查。

THG 效率随泵浦强度的二次标度需要微扰、未耗尽等条件，也需要可比的脉冲、共振和收集条件。不能只把两个不同研究的强度归一化，就确定材料优劣。

本归档保留生成的 Discussion 原文供读者判断，没有为了突出规则效果而重写输出。

## 6. 结论范围

这是单一环境、单一模型配置下，每类一个任务、每组两次的非盲案例。评分由 AI 助手完成并经本次归档复核，不是独立人工盲评；没有随机交错 before/after，没有显著性检验。现有材料支持“若干代码偏好得到更一致的遵循，以及写作措辞发生变化”，不支持规则普遍有效、全面提高科学正确性或已验证 Claude Code 的结论。
